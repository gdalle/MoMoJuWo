# More Modern Julia Workflows

A collection of resources on best practices for Julia development. This is an attempt at revamping the original [Modern Julia Workflows](https://modernjuliaworkflows.org/).

## Goals

Our purpose is to gather the hidden tips and tricks of Julia development, to make them easily accessible to beginners. We do not cover syntax, assuming that the reader is familiar enough with the [basics of Julia](https://julialang.org/learning/). Instead, we focus on all the tools and packages that make the coding experience more pleasant and efficient.

## Contents

There are three blog posts of increasing technical difficulty, plus one page of additional links:

1.  [Writing](pages/writing/index.llms.md): from zero to a basic script
2.  [Sharing](pages/sharing/index.llms.md): from a basic script to a reliable package
3.  [Optimizing](pages/optimizing/index.llms.md): from a basic script to a light-speed algorithm
4.  [Vibing](pages/vibing/index.llms.md): from a zero to a basic script you didn’t write
5.  [Going further](pages/further/index.llms.md): other websites to help you dive deeper into the rabbit hole

These are all fairly long and not meant to be read in one sitting, so take your time. Keep in mind that while each of these resources *can* be useful to you, not every one of them *will* be. But at least you will know where to look in case you have a specific question.

## Before you start

Many of the links you will see point to [GitHub](https://github.com/) repositories for Julia packages. When you click them, they will take you to a page called `README.md` that contains a brief description of the package, sometimes insufficient for actual use. You can usually find more thorough documentation by clicking on a blue badge called `docs|stable` looking like this ![badge](https://img.shields.io/badge/docs-stable-blue.svg) at the top of the `README`.
